# **App Name**: Akenna AI

## Core Features:

- Live Listening Mode: Continuously monitors audio input from the microphone to catch user queries without manual triggers.
- Intelligent Speech Response: Uses a tool-based LLM to reason and generate natural, contextual responses to spoken inquiries.
- Dynamic Facial Expression: Animate the interface by rendering a mouth that opens and syncs when the assistant is responding.
- Luminescent Visual State: Real-time visual feedback using the 'eyes' interface to show when the AI is processing or listening.
- Voice-to-Text Transcription: Instantly converts the always-on microphone audio into text data for processing by the core engine.
- Text-to-Speech Engine: Synthesizes the assistant's written reasoning into a clear, natural vocal performance.

## Style Guidelines:

- Primary color: Electric Cyan (#33E0FF), used for the glowing ocular elements and energetic states.
- Background color: Deep Abyss Black (#050E10), a desaturated, very dark base that allows the luminescent elements to pop.
- Accent color: Celestial Blue (#3377FF), an analogous shade used for subtle glows and depth within the interface.
- Headline and UI font: 'Space Grotesk' for a computerized, techy aesthetic that fits the futuristic AI assistant vibe.
- A purely minimalist, central-focus layout where the only visible interface elements are the abstract character features.
- High-fluidity motion blur for 'eye' movements and a smooth CSS transition for the revealing mouth during speech phases.
- Hidden icons only for critical mic access alerts, following a sleek and simple geometric style.
